## 前言

本文记录使用 Vue3 + Vite + Tailwind CSS 搭建纯静态个人博客的完整流程。

## 技术栈

| 技术 | 用途 |
|------|------|
| Vue 3 | 前端框架 |
| Vite | 构建工具 |
| Tailwind CSS | 样式框架 |
| Pinia | 状态管理 |
| Vue Router | 路由 |

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建部署
npm run build
npm run deploy
```
